# Arquitectura Web 2026 — Trabajos Prácticos

Cada TP está dentro del proyecto, en su propia carpeta y es independiente del otro.

## Ubicación de cada TP

- TP1: `src/main/java/org/example/TP1/`
- TP2: `src/main/java/org/example/TP2/`

Cada carpeta tiene su propia clase `Main`, así que se ejecuta el TP que se quiera
correr desde su `Main` correspondiente.
